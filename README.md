These are my final year project files.
The file named m10.py uses a virtual on screen keyboard.
The file named main.py has its own gui keyboard integrated in it to function.
The functioning is simple you just need to tilt your face to whichever side you want the cursor to move.
Stop wherever you want to stop and blink your eyes to click or select.
There is only one major limitation to this project that is the surrunding lighting.
It only works in proper light conditions. 
If it is not working properly then use your mobile torch light and point towards your face and see to it that it enlightens your eyes properly.
